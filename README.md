## ⚙️ Setup notes (for the snake & 3D graph)

Everything else in this README works immediately — just swap in your username where needed. Two widgets need a **one-time GitHub Action setup** because they generate an image file GitHub then displays:

1. Create a repo named exactly `princepandey3` (a "profile repo" — GitHub treats this specially).
2. Add the workflow files `snake.yml` and `profile3d.yml` (provided separately) into `.github/workflows/` in that repo.
3. Commit and push — the Actions will run automatically (and on a daily schedule after that), generating the SVGs the README links to.
4. Push this README.md as the repo's root `README.md`.
